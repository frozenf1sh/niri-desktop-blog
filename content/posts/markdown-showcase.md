## 引用与表格

> 写作的时候，先把想法记录下来，再慢慢整理。
>
> 引用也可以包含多个段落。

| 内容 | 写法 | 说明 |
| --- | --- | --- |
| 粗体 | `**文字**` | 强调重点 |
| 行内代码 | `` `code` `` | 标记代码或命令 |
| 链接 | `[文字](地址)` | 跳转到其他位置 |

## 代码块

代码块支持语法高亮与复制：

```js
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("Felix"));
```

```bash
pnpm check
pnpm build
```

不认识的语言会显示为纯文本：

```example
这里是一段纯文本。
```
